For Small Bites, use Tailwind v4 CSS-first tokens and React 19 ref props.
Use Base UI-backed shadcn components; replace Radix Slot/asChild examples with
Base UI composition rather than installing Radix dependencies. The Figma design
and root AGENTS.md take precedence over generic example styles or tooling.
Do not introduce testing tools or suites.
